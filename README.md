# 📌 Overview

ShopEase is a modern full-stack E-Commerce web application developed using the MERN Stack.

The application provides a complete online shopping experience with secure authentication, product browsing, shopping cart, wishlist, order management, checkout, and an admin dashboard for managing products, users, and orders.

This project was developed as part of the **CodeAlpha Full Stack Development Internship**.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Ansh-Kumar-296/CodeAlpha_ShopEase.git

cd CodeAlpha_ShopEase
```

---

# Install Client

```bash
cd client

npm install
```

---

# Install Server

```bash
cd ../server

npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGODB_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET_KEY

ADMIN_REGISTER_CODE=ShopEaseAdmin2026
```

Create `.env` inside the **client** folder.

```env
VITE_API_URL=http://localhost:5000/api
```

---

# ▶ Running Locally

## Backend
